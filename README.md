# TaskFlow — Mobile App Wireframing Project

A complete low-fidelity wireframing exercise for **TaskFlow**, a personal productivity and task management mobile application.

| Attribute       | Detail                                |

---

## Core Features Wireframed

1. **Onboarding** — Welcome, sign-up, and profile setup screens  
2. **Home / Dashboard** — Today's tasks, progress summary  
3. **Task Creation** — Add task with priority, due date, category  
4. **Task Detail** — View, edit, complete, delete a task  
5. **Categories** — Browse tasks by project/category  
6. **Profile & Settings** — User preferences  

---

## How to View the Wireframes

Open the interactive prototype in any browser:

```
design/wireframes/index.html
```

Use the navigation buttons on each screen to move between wireframe screens.

## Design Thinking Phases

| Phase       | Artifact                              |
|-------------|---------------------------------------|
| Empathize   | User interviews & surveys             |
| Define      | Problem statement & user personas     |
| Ideate      | Feature brainstorm & user flows       |
| Prototype   | Low-fidelity wireframes (HTML)        |
| Test        | Usability checklist & test scenarios  |

---

## Key Decisions

- **Low-fidelity style** — Grayscale, no real images, placeholder content only  
- **Mobile-first** — 390×844 (iPhone 14 viewport)  
- **Gesture-aware layouts** — Bottom navigation, swipe-friendly card lists
